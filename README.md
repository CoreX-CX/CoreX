# COREX v1.0.0 - MVP

This repository branch contains a Vite + React + TypeScript demo implementing the COREX v1.0.0 MVP UI.

Features included:
- Pages: Home, Store, Product Details, Contact, Login, Register
- Responsive design with dark theme (default)
- Reusable components: ProductCard, ProductGrid, SearchBar, CategoryFilter, Navbar, Footer
- Glassmorphism, neon accents, gradient accents
- Framer Motion micro-animations
- Demo product catalog (src/data/products.ts)

Not implemented (by design): payments, admin dashboard, orders or backend flows.

Run locally
1. Checkout branch corex-v1.0.0-mvp
2. npm install
3. npm run dev

Notes
- This is a frontend-only demo. Replace product data and wire up APIs as needed.
- Images use Unsplash demo URLs. Replace with your assets for production.

Version: COREX v1.0.0
